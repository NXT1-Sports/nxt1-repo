# Build and Deploy Quick Commands

## Web Deploy

### Production

```bash
npm run deploy:prod:no-test
```

### Staging

```bash
npm run deploy:staging:no-test
```

## OTA Updates (No Store Resubmission)

### Production iOS

```bash
npm run deploy:ota:ios
```

### Production Android

```bash
npm run deploy:ota:android
```

### Staging iOS

```bash
npm run deploy:ota:ios:staging
```

### Staging Android

```bash
npm run deploy:ota:android:staging
```
