# Coach's Guide: Agent X Practice Script Generator

**NEW CAPABILITY**: Automatically generate complete practice progressions in
seconds

---

## What It Does

Tell Agent X about a play or concept you want to teach, and it generates a
**complete 5–7 day practice progression** including:

✅ Daily objectives and time blocks  
✅ Drill boards (visual X-and-O diagrams for each drill)  
✅ Rep counts (automatically adjusted for your division)  
✅ Coaching cues and teaching points  
✅ Correction sequences for common mistakes  
✅ Success criteria to know when ready to deploy

---

## How to Use It

### Step 1: Open Agent X Chat

Navigate to the Agent X shell on web or mobile.

### Step 2: Ask for a Practice Progression

**Examples:**

```
"Build a 5-day install for our RPO"
"Create a practice plan for teaching Cover 2 recognition to our secondary"
"Design a drill progression for receivers running our inside zone reads"
"I need a practice schedule for our defensive line gap assignments"
"Build a 4-day rep progression for our OL combo blocks"
```

### Step 3: Provide Context (if asked)

Agent X might ask:

- What sport? (football, basketball, soccer, etc.)
- What level? (high school, college, professional)
- What install stage? (install, rep, or game-ready)
- How much practice time do you have?

### Step 4: Review & Download

Agent X returns:

- **Practice Playbook** — day-by-day schedule with drill diagrams
- **Coaching Cues** — teaching points for each day
- **Success Checklist** — know when the concept is ready for games

## Features by Install Stage

### Install Stage (Learning)

Agent X generates: foundational footwork → assignment clarity → unit
coordination  
Perfect for: teaching a brand new concept mid-season  
Example: "We want to add a new play to our offensive package"

### Rep Stage (Repetition)

Agent X generates: tempo coordination → read integration → early pressure  
Perfect for: taking a known concept and reinforcing execution  
Example: "Our zone read looks shaky; let's dial it in"

### Game-Ready Stage (Competition)

Agent X generates: full-speed execution → situational mastery → live pressure  
Perfect for: final week before playoffs or key conference games  
Example: "Lock down our core plays before conference championship"

## Tips for Best Results

### Provide Context

✅ **Good:** "Build a practice progression for our 'Trips Right Flood' passing
concept. We're college, 120-minute practices, and want install stage"

❌ **Vague:** "Practice plan"

### Ask for Sport & Division

✅ Agent X customizes rep counts differently for:

- High School (shorter practices, larger position groups)
- College (balanced, competitive level)
- Professional (higher intensity, longer prep)

### Specify Install Stage

- **Install** = teaching from scratch (go slower, more fundamentals)
- **Rep** = reinforcing known concepts (tempo, coordination)
- **Game-Ready** = final pressure testing before deployment

### Use the Drill Diagrams

Each day links to visual X-and-O diagrams. Print them or share digitally with
position coaches.

### Review & Adapt

Agent X generates a framework. Feel free to:

- Adjust rep counts for your roster
- Add weather considerations
- Compress if time is tight
- Extend if players need more reps

## FAQ

**Q: Can I adjust the progression after Agent X creates it?**  
A: Yes! Treat it as a draft. You can modify rep counts, add/remove drills, shift
timing. It's your practice.

**Q: Does this work for basketball, soccer, hockey?**  
A: Yes! Agent X is sport-agnostic. Specify your sport and it adjusts the
framework.

**Q: What if we have a shortened week?**  
A: Tell Agent X: "We have 75 minutes" and it'll compress the progression
accordingly.

**Q: Can I use this for off-season training?**  
A: Absolutely. Ask for "8-week skill development progression" and Agent X will
scaffold it.

**Q: How do I know when to move to the next day?**  
A: Agent X includes success criteria. Once met, advance. If not, repeat the day.

**Q: Can I combine concepts?**  
A: Yes. Ask: "Build a 7-day progression covering both our 'Power' run game and
'RPO' concepts" and Agent X will integrate them.
